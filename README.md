# Покращення та аналіз зображень відбитків пальців

STEM-проєкт з дисципліни «Комп'ютерна графіка та візуалізація».
Виконавець: Шмаркатюк Іванна, ІПЗ-23(06). Формат: індивідуально, варіант 2 (2 пайплайни).

Програма перетворює сирий скан відбитка на скелет папілярних ліній і знаходить
мінуції (закінчення та розгалуження ліній) двома різними пайплайнами, а потім
порівнює їх точність і стійкість до шуму. Усі методи реалізовано вручну на numpy.
Pillow використовується лише для читання/запису файлів, matplotlib лише для графіків.

## Пайплайни

| Стадія | П1 «Габор» | Категорія | П2 «Фур'є» | Категорія |
| --- | --- | --- | --- | --- |
| 1 | CLAHE | гістограмна корекція | ROI за робастною дисперсією блоків + нормалізація | аналіз текстур |
| 2 | Фільтр Габора за полем орієнтацій | фільтрація | Блокове FFT-підсилення (власне FFT) | перетворення Фур'є |
| 3 | Бінаризація Оцу | сегментація | Локальний поріг Sauvola | сегментація |
| 4 | Скелетування Zhang-Suen | морфологія | Відкриття + скелетування | морфологія |
| 5 | Мінуції (crossing number) | ключові точки | Мінуції (crossing number) | ключові точки |

```
П1: вхід → CLAHE → [поле орієнтацій → Габор] → Оцу → Zhang-Suen → мінуції
П2: вхід → [ROI → нормалізація] → FFT-підсилення → Sauvola → відкриття → Zhang-Suen → мінуції
```

Жоден метод не повторює методи лабораторних робіт №5-6 (Собел, Лаплас, Гаус,
медіанний тощо). Градієнт для поля орієнтацій береться центральними різницями.

## Встановлення

Потрібен Python 3.10+.

```
python -m venv .venv
.venv\Scripts\activate          # Windows;  Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```
python generate_synthetic.py --count 10 --out data/synthetic          # еталони для перевірки
python generate_synthetic.py --count 10 --seed 100 --out data/synthetic_tune
python run.py --pipeline all                                          # обидва пайплайни
python run.py --pipeline p1 --input data/fvc2002 --limit 20           # лише П1, 20 файлів
python run.py --pipeline p2 --set p2.sauvola.k=0.2                    # змінити параметр
```

Синтетичні набори вже лежать у `data/`, тому перші два рядки потрібні лише для
повторної генерації. Як завантажити основну вибірку FVC2002, описано в `data/fvc2002/README.md`.

Результати `run.py` (папка `results/`):
- `p1/<файл>/`, `p2/<файл>/`: вихід кожної стадії (`1_clahe.png`, `2_gabor.png`, ...)
  і `5_minutiae.png` (червоні - закінчення, зелені - розгалуження);
- `metrics.csv`: для кожного зображення кількість мінуцій, MSE/PSNR/SSIM відносно входу, час;
- `summary.json`: середні значення; `errors.json`: пропущені файли з причиною.

## Експерименти

```
python experiment.py groundtruth                        # точність на еталонах (C1)
python experiment.py robustness --input data/fvc2002    # стійкість до шуму (C1, B2)
python experiment.py sweep                              # підбір параметрів
python experiment.py figures --input data/fvc2002       # рисунки стадій для звіту
python benchmark.py                                     # наївні vs оптимізовані версії
```

| Режим | Що робить | Файли в `results/experiments/` |
| --- | --- | --- |
| groundtruth | Порівнює результат з відомою відповіддю синтетичних відбитків: похибка орієнтації, збіг маски ліній, повнота мінуцій | `groundtruth.csv`, `c1_groundtruth.json` |
| robustness | Додає шум (гаусів, імпульсний, нерівне освітлення) і порівнює вихід на зашумленому і чистому зображенні: SSIM, PSNR, MSE, частка збережених мінуцій | `robustness.csv`, `robustness_summary.csv`, `robustness.png`, `c1_robustness.json` |
| sweep | Змінює по одному параметру й вимірює збіг з еталоном при шумі σ=20 на окремому наборі `synthetic_tune` | `sweep.csv`, `sweep.png` |
| figures | Рисунок з усіма стадіями обох пайплайнів | `stages_<файл>.png` |

Порогові значення з ТЗ задані в `config.yaml` (секція `experiment.thresholds`):
SSIM ≥ 0,70, PSNR ≥ 20 дБ, збережено ≥ 70% мінуцій, похибка орієнтації ≤ 5°,
збіг бінаризації ≥ 95%. Усі випадкові компоненти мають фіксований seed.

## Конфігурація

Усі параметри методів лежать у `config.yaml` з коментарями. Будь-який параметр можна
перевизначити з командного рядка: `--set p1.gabor.sigma_y=4`.
Значення `sigma_y`, `fft.k` і `sauvola.k` обрано за результатами `experiment.py sweep`.

## Тести та якість коду

```
python -m pytest            # 40 автотестів
pylint fp tests *.py        # статичний аналіз
```

Кожен метод і пайплайн має щонайменше один тест на маленькому зображенні
з очікуваним результатом, порахованим вручну (наприклад, Оцу на 6 пікселях,
Sauvola на 5x5, FFT вектора [1, 0, 0, 0], скелет квадрата 3x3 - одна точка).
Окремо перевіряються крайові випадки: порожній, пошкоджений, замалий, кольоровий,
16-бітний та однобітний файли (програма пропускає погані файли без аварійного завершення).

## Структура

```
fp/
  core.py            згортка, інтегральне зображення, сірий колір
  io_utils.py        читання файлів з обробкою крайових випадків
  metrics.py         MSE, PSNR, SSIM, збереження мінуцій, кутова похибка
  noise.py           контрольовані спотворення
  synthetic.py       генератор синтетичних відбитків з еталонами
  pipelines.py       П1 і П2, збереження проміжних результатів
  config.py          читання config.yaml і --set
  methods/
    clahe.py         CLAHE
    orientation.py   поле орієнтацій, частота ліній
    gabor.py         фільтр Габора (оптимізована + 2 повільні версії)
    otsu.py          метод Оцу
    roi.py           ROI за дисперсією, нормалізація
    fft.py           власне FFT (Cooley-Tukey)
    fft_enhance.py   блокове частотне підсилення
    sauvola.py       метод Sauvola
    morphology.py    ерозія, дилатація, відкриття, закриття
    thinning.py      Zhang-Suen (векторизована + наївна версії)
    minutiae.py      crossing number, фільтрація хибних мінуцій
run.py               головна програма
experiment.py        експерименти
benchmark.py         порівняння швидкості
generate_synthetic.py
config.yaml
tests/
data/synthetic/      10 еталонів для перевірки (PNG + _gt.npz)
data/synthetic_tune/ 10 окремих еталонів для підбору параметрів
data/fvc2002/        основна вибірка (завантажується окремо)
```
